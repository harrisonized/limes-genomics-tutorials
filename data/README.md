## Data for bulkrnaseq.R

Go to NCBI GEO [GSE63310](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE63310), scroll to the bottom of the page and click on GSE63310_RAW.tar (custom download). Unzip it and place the unzipped directory in the data folder.

Also download the GSE63310\_series\_matrix.txt.gz file located [here](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE63nnn/GSE63310/matrix/) and place it in the data folder.
